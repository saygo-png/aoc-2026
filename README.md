# Advent of Code 2026

My attempt at AOC 2026

## Daily loop

1. Paste the example from the puzzle into `inputs/05.example.txt` and input into `inputs/05.txt`.
2. Run `watch 5` and edit `src/Day05.hs`. Each time you save, it reloads and prints:

   ```
   example part 1: 142
   example part 2: 0
   input part 1: 54632
   input part 2: 0
   ```
